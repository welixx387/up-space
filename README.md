# Ап Спейс

Сайт студии Ап Спейс: альфагравити, массаж, йога, растяжка и телесные практики.
Санкт-Петербург, Загородный проспект, 37.

## Как устроено

- `index.html` — сайт. Редактируемые места помечены `data-edit` (текст), `data-img` (фото), `data-code` (код двери).
- `content/site.json` — правки из админки. Его пишет только админка.
- `build.js` — при деплое подставляет правки в страницу и собирает `dist/`.
- `admin.html` + `api/` — админка по адресу `/admin`.

## Админка

Открыть `/admin`, ввести пароль, нажимать на текст и фото прямо на странице, затем «Сохранить».
Правки сохраняются коммитом в этот репозиторий, Vercel пересобирает сайт примерно за минуту.

Переменные окружения в Vercel (Settings → Environment Variables):

| Переменная | Значение |
|---|---|
| `ADMIN_PASSWORD` | пароль для входа в админку |
| `GITHUB_TOKEN` | fine-grained token GitHub с доступом только к `welixx387/up-space`, право **Contents: Read and write** |

После добавления переменных нужен повторный деплой (Deployments → Redeploy).
