# Ап Спейс

Сайт студии Ап Спейс: альфагравити, массаж, йога, растяжка и телесные практики.
Санкт-Петербург, Загородный проспект, 37.

## Как устроено

- `content/site.json` — всё содержимое сайта: тексты, направления, расписание, мастера, фото, контакты. Его меняет админка.
- `site.template.html` — вёрстка, стили и анимация.
- `lib/render.js` — собирает страницу из шаблона и данных. Тот же файл работает в предпросмотре админки.
- `build.js` — сборка в `dist/` при деплое на Vercel.
- `admin.html`, `api/`, `lib/schema.js`, `lib/github.js` — админка `/admin` и её сервер.

## Админка

`/admin`, вход по паролю. Вкладки: Главная, О студии, Направления, Расписание, Мастера, Как пройти, Контакты.
Направления, мастера, преимущества и занятия в расписании можно добавлять, удалять и менять местами.
«Сохранить» делает коммит в этот репозиторий, Vercel пересобирает сайт примерно за минуту.

Переменные окружения в Vercel:

| Переменная | Значение |
|---|---|
| `ADMIN_PASSWORD` | пароль админки |
| `GITHUB_TOKEN` | fine-grained token с доступом только к этому репозиторию, **Contents: Read and write** |

Перед своими правками в коде: `git pull --rebase`, потому что админка тоже коммитит в `main`.
